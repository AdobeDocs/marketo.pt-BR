# Adicionar um link a uma imagem de página de destino de forma livre {#add-a-link-to-a-free-form-landing-page-image}

>[!PREREQUISITES]
>
>[Adicionar uma imagem a uma página de aterrissagem de forma livre](/help/marketo/product-docs/demand-generation/landing-pages/free-form-landing-pages/add-an-image-to-a-free-form-landing-page.md)

>[!NOTE]
>
>Isso se aplica somente às páginas de aterrissagem de forma livre.

1. Selecione a imagem adicionada à página de aterrissagem e expanda a **[!UICONTROL Folha de Propriedades]**.

   ![](assets/image2014-9-18-15-3a29-3a0.png)

1. Digite o link mailto em **[!UICONTROL linkUrl]**.

   ![](assets/image2014-9-18-15-3a29-3a21.png)

   Agora você tem uma imagem como um link mailto na página de aterrissagem do Marketo.

   ![](assets/image2014-9-18-15-3a29-3a38.png)
