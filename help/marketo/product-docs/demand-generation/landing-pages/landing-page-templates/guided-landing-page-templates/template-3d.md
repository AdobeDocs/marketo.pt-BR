# Modelo 3D {#template-3d}

Clique com o botão direito do mouse em [baixar Modelo 3D](https://51837-micrositemarketo.adobeio-static.net/lp-templates/template-3d.html) e selecione **Salvar link como...**

>[!NOTE]
>
>As etapas completas sobre como baixar e importar um modelo [podem ser encontradas aqui](/help/marketo/product-docs/demand-generation/landing-pages/landing-page-templates/guided-landing-page-template-list.md#how-to-import){target="_blank"}.

![](assets/image2015-6-15-11-3a29-3a7.png)

Esse template inclui o seguinte conteúdo:

* Um cabeçalho com logotipo e 3 botões (opcional)
* Uma seção principal

  * inclui texto herói.

* Três seções do corpo (opcional)
* Rodapé (opcional)
